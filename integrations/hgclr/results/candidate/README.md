# Candidate historical aggregates

These files were exported from the working HGCLR server checkout on 2026-07-17.
They contain five-seed test, validation and cost aggregates for WebOfScience,
NYT and RCV1.

They have not yet been reconciled with the final paper tables. Until that check
is complete, they are historical candidate results rather than verified release
results. The cost measurements also predate the CUDA timing synchronisation
added during release hardening.
